# 📂 OpenPath

OpenPath é um gerenciador de arquivos moderno desenvolvido com **C#**, **.NET** e **Avalonia UI**, focado em desempenho, simplicidade e uma experiência agradável para o usuário.

## ✨ Funcionalidades

* 📁 Navegação por diretórios
* 📄 Visualização de arquivos
* 🔍 Pesquisa de arquivos e pastas
* ⚡ Interface leve e rápida
* 🖥️ Suporte multiplataforma com Avalonia UI

## 🚀 Tecnologias

* C#
* .NET
* Avalonia UI

## 🛠️ Como Executar

Clone o repositório:

```bash
git clone https://github.com/Kaikygabriel/Open-Path-.git
```

Acesse a pasta do projeto:

```bash
cd Open-Path-
```

Execute a aplicação:

```bash
dotnet run --project src/OpenPath/OpenPath.UI
```

## 🎯 Objetivo

O OpenPath nasceu como um projeto de estudo e portfólio, com o objetivo de explorar desenvolvimento desktop moderno utilizando .NET e Avalonia UI, evoluindo gradualmente para um gerenciador de arquivos completo e eficiente.
